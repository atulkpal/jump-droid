# Jump Droid Release Notes — v2.2.1 "Tactical Terminal"

**Release Date:** 2026-07-30
**Build Version:** v2.2.1
**Status:** Production Ready

## Executive Summary
Version v2.2.1 introduces the "Pilot Command Center," a high-fidelity overhaul of the Local Telemetry system, providing pilots with granular combat and skill statistics. This update also stabilizes the multi-stat progression requirements for Zen and Multiplayer protocols, housed within a new "Vector-Scope" CRT console.

---

## New Feature: Pilot Command Center (Sector: Local)
- **High-Density Telemetry**: Access a 2x4 grid of critical flight data including Altitude, Max Combo, Bosses Slayed, Threats Escaped, Continues Used, Cash Earned, and Perfect Landings.
- **Terminal Vitality**: Injected life into the UI with staggered "System Boot" entrance animations and a real-time vertical radar sweep.
- **Intelligent Threat Log**: A filtered neutralization log that exclusively lists encountered bosses (Slayed/Escaped/Defeated By), preserving the mystery of undiscovered threats.
- **Discovery Progress**: A new glowing progress bar tracks your journey through the fleet's threat database.

## Redesigned: Vector-Scope CRT Console
- **Tactical Monitor Aesthetic**: The Zen/Multiplayer box has been replaced with an immersive CRT monitor effect featuring scanlines and periodic flickering.
- **Real-Time Waveform**: A vector-scope visualizer that stabilizes as you progress towards protocol authorization.
- **Stable State Protocol**: Meaningful color states (Green, Amber, Purple, Cyan) replacing previous "disco" cycling for better legibility and immersion.

## Improvement: Intelligence & Progression
- **Tripartite Zen Unlock**: Restored Altitude, Bosses, and Combo requirements for Zen authorization.
- **Uplink Protocol (Multiplayer)**: Demanding veteran requirements (25Km, 10 Bosses, 5x 20-combo) to ensure long-term pilot engagement.
- **Tactical Defeat Attribution**: Active bosses now correctly "claim" player defeats in the permanent record if a run ends while they are on-screen.

## Refinement: "Archive Intelligence"
- **Droid-Centric Rewards**: Renamed the reward sync action and added prominent "Value Badges" to cards (e.g., "+500 JC").
- **Buffer Flush Animation**: Optimized the card dissolution effect with a "SYNCING..." tactical overlay.

## Fixes & Stability
- **Safe Resume Safety**: Implemented safety handlers to ensure the game resumes if overlays are dismissed by system back gestures.
- **HUD De-clutter**: Removed the redundant '?' button from the HUD, consolidating information in the Pause menu.
